What is a blockchain?

A blockchain is a digital record system where information is stored in connected blocks.

▧

What is a block?

A block is a container for information. In this demo it holds anonymized votes, a timestamp, and a cryptographic hash.

#

What is hashing?

Hashing turns information into a fixed-length digital fingerprint. BlockVote calculates these fingerprints with SHA-256.

↗

What is a previous hash?

It links a new block to the block before it. If an earlier block changes, the link no longer matches.

⚡

Why is it tamper-evident?

Changing old information changes its hash. The following block still points to the old hash, revealing the change.

①

What is the Genesis Block?

The Genesis Block is the first block in a blockchain. It starts the chain and has no previous block.

Know the limits

“This project demonstrates blockchain concepts through a local JavaScript simulation. It is designed for educational purposes and is not suitable for real public elections.”

LocalStorage is not secure, decentralized, or immutable. This browser demo has no distributed nodes and SHA-256 alone does not make an election secure.
