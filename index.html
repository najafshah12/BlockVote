How the chain works

A short guide to the records you see in the explorer.

▤

Blockchain

A digital record made from linked blocks.

▧

Block

A record with data, a time, and its hash.

#

Hash

A SHA-256 fingerprint calculated from a block’s contents.

↗

Previous hash

The hash that connects a block to the one before it.

⚡

Tamper check

Change old data and its hash no longer matches. Later blocks then fail the link check.

①

First block

The Genesis Block starts the chain and has no earlier block to link to.

About this system

BlockVote shows how linked records work using JavaScript in one browser. It is for education and is not suitable for real public elections.

LocalStorage is not secure or immutable. This browser does not use a network of independent computers. SHA-256 alone cannot secure an election.
BlockVote is an educational simulation · No real votes are collected · About
